# 拉了吗

> 一个用来记录排便情况的 Android App —— 用最低的操作成本，把肠道健康最直观的三个指标记下来。

排便的**形状、颜色、频次**是肠道健康非常直接的信号，但很少有人会认真记录。
「拉了吗」把这件事压缩成「点一下 ＋、滑三下、保存」，并且自动算出健康分、生成阶段性总结。

界面走暖黄色 + 毛玻璃风格，所有交互都带过渡动效。

---

## 功能

### 记一次，三下滑完

点右上角的 **＋**，面板自下而上滑出：

- **时间** —— 默认当前时间，可点开日历 / 时钟精确到分钟
- **形状** —— 滑杆 5 档：羊粪球 / 干硬块 / 黄金便 / 软香蕉 / 水样便
- **颜色** —— 滑杆 6 档：深褐 / 标准棕 / 浅棕黄 / 油黄 / 绿色 / 灰白（滑杆轨道本身就是颜色预览）
- **残留** —— 滑杆 5 档：一擦就净 / 轻微 / 中等 / 较多 / 擦不完

滑的时候顶部的**健康和分数实时变化**，拖到不健康的档位会立刻变成「注意 / 警报」。
滑杆带逐档触感反馈，跨过档位时震一下。

### 一眼看出哪次不正常

主界面按时间倒序排列，自动按「今天 / 昨天 / 周几」分组。每条记录是一个横条：

```
┌──────────────────────────────────────────────────┐
│  🌟    ▁▃▅▆█     13:07      形状 💩 ● 黄金便   🗑  │
│ 优秀              颜色 🟤 ● 标准棕                │
│  98               残留 🧻 ● 轻微                  │
└──────────────────────────────────────────────────┘
   健康程度            细节（小字）          删除
```

- **左边**是这条记录的健康程度：情绪图标 + 能量柱 + 等级 + 分数
- **中间**是细节
- **右边**是删除按钮，点一下整条滑出并消失
- 点横条本身可以编辑

### 阶段总结

左上角「总结」进入，可选 **近 7 天 / 近 30 天 / 本月 / 今年 / 全部**，或拉日历自定义区间。

给出：

- 健康分环 + 等级 + 总次数 + 日均频率
- 关键指标：记录天数、理想成形次数、残留偏多次数、最常见形状 / 颜色、高频时段
- 形状 / 颜色 / 残留三张分布图
- 每日次数趋势图
- **一段人话总结**，比如「有 70% 是理想成形便，肠道状态很稳」「日均不到 0.3 次，可能有点便秘倾向」

## 健康分是怎么算的

权重 **颜色 50% + 形状 40% + 残留 10%**。颜色权重最高，因为灰白、发黑这类信号在医学上更值得警惕。

三个维度各自的子分都能取到 0 或 100，加权后映射到**真正的 0~100**：

- 羊粪球 + 灰白 + 擦不完 = **0 分**
- 黄金便 + 标准棕 + 一擦就净 = **100 分**

| 分数 | 等级 |
| --- | --- |
| 85-100 | 🌟 优秀 |
| 70-84 | 😊 良好 |
| 50-69 | 😐 一般 |
| 30-49 | 😟 注意 |
| 0-29 | 🚨 警报 |

> ⚠️ 分数和总结只是基于你自己记录的数据做的趣味化提示，**不能代替医生的诊断**。
> 如果出现持续灰白、发黑、带血，或长期腹泻 / 便秘，请及时就医。

## 自己编译

环境：JDK 17 + Android SDK（platform 34）

```bash
git clone https://github.com/mousemaster114/laleme.git
cd laleme
./gradlew assembleRelease
```

产物在 `app/build/outputs/apk/release/`。

Windows 上也可以用一键脚本：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

<details>
<summary>技术栈与项目结构</summary>

**Kotlin + Jetpack Compose (Material 3) + Room + ViewModel**，单 Activity，无第三方 UI 库。

```
app/src/main/java/com/laleme/app/
├─ MainActivity.kt
├─ data/                    纯 Kotlin 数据层（不依赖 Compose，可单测）
│  ├─ Enums.kt              形状 / 颜色 / 残留
│  ├─ PoopEntry.kt          Room 实体
│  ├─ PoopDao.kt / PoopDatabase.kt / PoopRepository.kt
│  └─ HealthScore.kt        健康评分 + 总结分析
└─ ui/
   ├─ AppRoot.kt            页面切换 + 弹层宿主
   ├─ PoopViewModel.kt      状态与时间段管理
   ├─ theme/                黄色主题
   ├─ components/GlassKit.kt 毛玻璃卡片、滑杆、能量柱等公共组件
   └─ screens/              主界面 / 添加面板 / 总结页
```

**视觉实现**：毛玻璃不是半透明贴图 —— 每张卡片内部有一层暖色渐变 + 两个**真实高斯模糊**
（`Modifier.blur`）的大色斑，色斑缓慢游走呼吸，所以卡片里的模糊是活的。

**测试**：`app/src/test/` 下有 16 个纯逻辑单元测试（评分边界、天数计算、分布统计）。

</details>
